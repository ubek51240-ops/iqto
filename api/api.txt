------------------------------------------------
  AUTENTIFIKATSIYA (AUTHENTICATION)
------------------------------------------------

Admin himoyalangan yo'llar uchun 2 xil usul mavjud:

  1) Session (brauzer cookie orqali)
     - Admin login qilinganidan keyin avtomatik ishlaydi

  2) Bearer Token (Header orqali)
     - Login javobidan "token" olinadi
     - Har so'rovga qo'shiladi:
       Authorization: Bearer <token>

------------------------------------------------
  ADMIN AUTH API
------------------------------------------------

[1] Admin Login
    METHOD  : POST
    URL     : /api/admin/login
    AUTH    : Yo'q (ochiq)
    Body (JSON):
      {
        "username": "admin",
        "password": "123"
      }
    Muvaffaqiyatli javob (200):
      {
        "success": true,
        "message": "Admin paneliga xush kelibsiz!",
        "token": "<bearer_token>"
      }
    Xato javob (401):
      {
        "success": false,
        "message": "Login yoki parol noto'g'ri!"
      }

  SOCKET.IO REAL-TIME VOQEALAR
------------------------------------------------

  Real-time chat va buyurtma bildirishnomalar uchun
  Socket.IO ishlatiladi. REST API bilan bir xil backendda.

  [Ulanish]
    const socket = io("https://your-backend.com");

  [Foydalanuvchi Chat Xonasiga Qo'shilish]
    socket.emit("join_chat", { session_id: "abc123" });

  [Admin Xonasiga Qo'shilish]
    socket.emit("join_admin");

  [Xabar Yuborish]
    socket.emit("send_message", {
      session_id: "abc123",
      sender: "user",
      user_name: "Sardor",
      message: "Salom!"
    });

  [Xabar Olish]
    socket.on("receive_message", (data) => {
      // data: { session_id, sender, user_name, message, timestamp, total_unread }
    });

  [Yangi Buyurtma Bildirishnomasi - Admin]
    socket.on("new_order", (order) => {
      // order: { order_id, customer_name, phone, items, total_price, status, ... }
    });

  [Buyurtma Statusi O'zgardi]
    socket.on("order_status_updated", (data) => {
      // data: { order_id, status }
    });

------------------------------------------------
  MA'LUMOTLAR BAZASI JADVALLARI (DATABASE SCHEMA)
------------------------------------------------

  books:
    id, title, author, price, old_price, category, type,
    rating, tag, tag_type, image, stock, description

  orders:
    order_id, customer_name, phone, address, payment_method,
    items_json, total_price, status, created_at

  users:
    id, name, email, password, phone

  favorites:
    id, user_email, book_id

  comments:
    id, book_id, user_name, comment_text, likes,
    replies_json, created_date

  chat_messages:
    id, chat_session_id, sender, user_name, message,
    timestamp, is_read

  settings:
    key, value

------------------------------------------------
  XATO KODLARI
------------------------------------------------

  200  - Muvaffaqiyatli
  204  - OPTIONS (CORS preflight)
  400  - Noto'g'ri ma'lumot kiritildi
  401  - Autentifikatsiya xatosi (login/parol)
  403  - Ruxsat yo'q (admin kerak)
  404  - Ma'lumot topilmadi
  500  - Server ichki xatosi
